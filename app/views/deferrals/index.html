Error messages

Dates are optional, but if a value has been added (and the main 'Select' button selected):

  • The extension of time date must include a day
  • The extension of time date must include a month
  • The extension of time date must include a year
  • The extension of time date must be a real date
  • The extension of time date must be in the future
  • Year must include 4 numbers

Some (to be confirmed) requirements include:

  • The new extention date must be later than the date already in use on the application: This will require an additional error message (see above) ***
  • Dates must be a working day. The custom days should automatically count only working days. The date entry form must fire a validation message if the date is not a working day (see above) ***
  • We may need to improve the hint text for dates with an explaination: e.g, "Extend the .... date".
